# x12-proto — memory-safe protocol front-end

Rust crate that **decodes and validates** untrusted X11 request bytes for the
native **X12-SURFACE** path before they reach the C server core.

See [ADR-0011](../../docs/adr/0011-rust-protocol-frontend.md) and
[docs/SAFE_PROTO.md](../../docs/SAFE_PROTO.md).

## Build / test

```bash
cargo test --manifest-path safe/x12-proto/Cargo.toml
# or
./tests/safe_proto/run.sh
```

## C ABI

Header: [`include/x12_proto.h`](include/x12_proto.h)  
Entry: `x12_proto_decode_surface(...)` — returns status codes; does not yet
dispatch into dix.

## Scope (spike)

| In | Out |
|---|---|
| X11 request framing | Full xproto codec |
| X12-SURFACE opcodes | Server request-loop hookup |
| Level gate (sandbox/user/full) | FD passing / compositor |
| Unit tests + CI cargo test | Autogenerated from XML (later) |
